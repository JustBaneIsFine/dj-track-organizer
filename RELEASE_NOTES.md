### Added

- **Open artist settings** in the track right-click menu. It opens the artist's settings without changing the current filters.

### Changed

- **Switching filters is faster on large libraries.** The first screen of tracks shows right away and the rest load in behind it, so the filter highlight no longer stutters.
- **Track right-click menu** opens instantly instead of animating each item in. Mark as listened, Revisit later and Open link were removed from it, since the row already has buttons for them.

### Fixed

- **Arrow keys and clicks** lagged in lists with thousands of tracks.
- **Changing a filter** briefly showed the new tracks before their animation started.
